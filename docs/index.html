Lecture Notes Viewer

Slides plus a transcript in, a properly written set of lecture notes out — figures embedded, cross-referenced against everything covered earlier in the course. Runs on your own Mac, on your own API key.

Download the installer macOS · one file · takes about three minutes end to end
First double-click will be blocked. macOS refuses to run any downloaded script the first time. Right-click (or Control-click) the downloaded file → Open → Open. Once only.

Rather skip that? Paste this into Terminal instead — same installer, no warning: 
curl -fsSL https://raw.githubusercontent.com/Jonah-Keller/lecture-notes-viewer/main/install.sh | bash

What happens after you run it

  1. It installs Apple's command line tools if you don't already have them (a system popup — click Install).
  2. It downloads the app and puts Launch Lecture Notes on your Desktop.
  3. Your browser opens on the Setup page.
  4. Paste an Anthropic API key, pick a model, load the shared lecture pack. Done.

Every time after that, you just double-click the Desktop launcher.

The two things Setup asks for

An Anthropic API key

Create one at console.anthropic.com/settings/keys and put a few dollars of credit on it. Generation is billed to your account, not anyone else's, and the key is written to a file on your Mac — it never leaves it. The default model is Sonnet, at roughly $0.25–0.60 per lecture; Haiku is a few cents if you want it cheaper, Opus is there for a lecture that's mostly diagrams.

A library pack

A single .zip of courses that are already written up — the notes and every slide image. Load it on the Setup screen and it copies straight onto your machine: nothing regenerates, no API credit is spent, and you can read all of it without a key at all.

Start with the samples if you just want to see what the notes look like.

See what the notes look like

The sample pack is seven lectures — the three spinal cord lectures from Brain and Behavior, pituitary physiology followed by pituitary pathophysiology, and gastric motility followed by its pharmacology. They're deliberately consecutive pairs, because the thing worth judging is how the second lecture of a pair refers back to the first instead of re-explaining it.

Then what

Read and search everything in the pack. To add a lecture of your own, hit New lecture, drop in the slide PDF and the transcript, and the notes are drafted in the background while you do something else. Review the draft, publish it, export a PDF.

If something goes wrong

Almost everything is one of three things: the Gatekeeper warning above, a missing Xcode command line tools install (xcode-select --install), or something else already sitting on port 8080. The README has the rest.
