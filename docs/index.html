PSOM

Lecture notes, written for you

Hand it a lecture's slide PDF and the transcript. Get back a proper set of notes with the slides embedded where they belong — and written knowing what the earlier lectures in that course already covered, so it points back instead of repeating itself.

Runs on your own Mac. Reading the shared notes is free and needs no account. Three steps, about five minutes.

1

Install it

Download this, then double-click it. It does the rest on its own.

Download the installer
macOS will block it the first time. That's expected — it blocks every downloaded script. Right-click (or Control-click) the file you just downloaded → Open → Open. You only do this once.

Rather not deal with that? Paste this into Terminal instead — identical installer, no warning: 

curl -fsSL https://raw.githubusercontent.com/Jonah-Keller/lecture-notes-viewer/main/install.sh | bash

A Terminal window opens and narrates what it's doing: Apple's command line tools if you don't have them (a system popup — click Install), then the app, then a Launch Lecture Notes shortcut on your Desktop. Your browser opens when it's ready. Every time after this, you just double-click that Desktop shortcut.

2

Load the lectures

The app opens empty. The notes come as a .zip you download once and load on the Setup screen — a straight copy onto your machine. Nothing regenerates and nothing is charged.

Download one, then on the Setup screen hit Load — it finds a pack sitting in your Downloads folder by itself. If you're just having a look, take the samples; the full library is 676 MB.

The seven samples are the three spinal cord lectures from Brain and Behavior, pituitary physiology followed by pituitary pathophysiology, and gastric motility followed by its pharmacology. The pairs are the point — read the second of each and watch how it leans on the first rather than starting over.

The full library is Endocrine, GI, Reproduction and the start of Brain and Behavior — around 100 lectures.

That's it if you only want to read. No key, no account, no cost. Step 3 is only if you want to make your own.

3

Optional — write up your own lectures

To generate notes you need an API key, because that part costs real money and it should be your money, not someone else's.

Make one at console.anthropic.com/settings/keys, put about $10 on it, paste it into the Setup screen. That's roughly 20–40 lectures on the default model, and there's a cheaper one in the dropdown if you want to stretch it further. The key is written to a file on your Mac and goes nowhere else.

Then: New lecture → drop in the slide PDF and the transcript → it drafts in the background while you do something else. Review, publish, export a PDF.

If something goes wrong

"cannot be opened because it is from an unidentified developer"

Normal, and the most common thing people hit. macOS refuses to run any downloaded script on the first double-click.

Right-click (Control-click) the file → Open → Open. If your Mac doesn't offer Open at all, go to System Settings → Privacy & Security, scroll to the bottom, and click Open Anyway.

Or skip it entirely with the Terminal one-liner in step 1.

"git: command not found"

Apple's command line tools aren't installed. In Terminal run xcode-select --install, click Install in the popup, wait for it to finish, then run the installer again.

The Terminal window closed instantly

It's set to stay open and show the error. If it still vanishes, open Terminal and run ~/lecture-notes-viewer/start.sh directly — whatever failed will be printed.

The browser didn't open, or the page won't load

Give it a minute on first run — it's building a Python environment and downloading Chromium for PDF export. Then go to localhost:8080 yourself. If it says the port is in use, quit whatever else is on 8080.

The "New lecture" button is greyed out

No API key yet — that's step 3, and it's only needed for generating. Reading everything in the packs works without it.

Loading the pack seems stuck

The full library is 676 MB and unpacks thousands of slide images. A minute or two is normal. Leave the tab open.

Worth knowing

The slide images in these notes are our lecturers' material, so keep the packs inside the class — don't repost them.

The notes are model-generated. They're good and they're checked against the transcript, but they are not a primary source. Verify anything before you commit it to memory.

Updates arrive on their own — the Desktop launcher pulls the latest version every time you start it.
